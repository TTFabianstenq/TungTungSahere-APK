# Tung Tung Sa Here - Android App

Simple app that shows the Tung Tung image and plays the sound on loop at full volume.

## Build with GitHub Actions

The repo has a workflow that automatically builds the APK.

Go to the **Actions** tab → select the latest successful run → download the **TungTungSaHere-APK** artifact.

## Local build

1. Install Android Studio
2. Open this folder
3. Build → Build Bundle(s) / APK(s) → Build APK(s)

## Features
- Fullscreen image of Tung Tung
- Plays the MP3 on infinite loop
- Volume set to 100%
- Keeps screen on
- Portrait orientation
